### [Simulaciones Monte Carlo para calcular integrales de camino](https://github.com/cuaub23/Monte-Carlo-Simulations-For-Path-Integral-Calculations)

<details>
<summary>Detalles</summary>

Este proyecto utiliza simulaciones Monte Carlo mediante el algoritmo de Metropolis para calcular integrales de camino.

De forma esquemática, una integral de camino puede representarse como un producto infinito de integrales sobre $\mathbb{R}$.

**Tecnologías utilizadas:**

- Python
- SciPy
- NumPy
- IPython

</details>

### [Cálculo del espectro de la cuerda heterótica con grupo de norma $E_8 \times E_8$](ENLACE_AL_REPOSITORIO)

<details>
<summary>Detalles</summary>

Este proyecto implementa un algoritmo para determinar el espectro resultante de una compactificación de la cuerda heterótica con grupo de norma $E_8 \times E_8$ en el orbifold $T^6 / \mathbb{Z}_7$.

El algoritmo genera vectores que cumplen ciertas condiciones y filtra un conjunto de vectores mediante restricciones adicionales.

**Tecnologías utilizadas:**

- Python
- NumPy
- itertools
- fractions
- JSON

</details>
